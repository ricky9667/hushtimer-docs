# HUSH Timer Documentation

This is the development & testing documentation of [HUSH Timer](https://hushtimer.app/).

## Development

This documentation uses [MkDocs](https://github.com/mkdocs/mkdocs) and the [Material for MkDocs](https://github.com/squidfunk/mkdocs-material) theme.

### Install packages

```bash
pip3 install -r requirements.txt 
```

### Run the docs locally

```bash
mkdocs serve
```

## Contribution

If you want to add/edit this documentation, open a new branch and create a pull request.
